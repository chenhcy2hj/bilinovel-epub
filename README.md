# 哔哩轻小说 (linovelib) 分卷 EPUB 下载器

在哔哩轻小说（linovelib）的**分卷详情页**注入一个「EPUB下载」按钮，一键把整卷正文与插图打包成 EPUB 2.0 电子书。

- 版本：**v1.6.0**
- 脚本：[`bilinovel-epub.user.js`](./bilinovel-epub.user.js)
- 运行环境：Tampermonkey（油猴），纯单文件，无第三方依赖

## 功能

| 能力 | 说明 |
| :--- | :--- |
| 一键成书 | 当前分卷 → 一个 `.epub` 文件，含封面、书名/卷名、章节目录与插图 |
| 分卷入口 | 只在 `/novel/{id}/vol_{n}.html` 显示按钮，书籍页、目录页不注入 |
| 章节顺序 | 按分卷页目录顺序抓取，章节内多页自动翻页合并，`cid(0)` 缺链章节双向补齐 |
| 正文还原 | 站点在页面加载约 2.5 秒后才还原段落顺序，脚本等还原完成再取文，导出不会出现乱序段落 |
| 字体解密 | 自动还原 `readfont` PUA 混淆字符（内置 3500 字字典 + TTF 字形轮廓 Hash），支持导入自定义字典 |
| 插图处理 | 并发下载 + 失败重试，图床异常时按宽限期跳过并降级为占位提示，不阻塞整卷 |
| EPUB 2.0 | 自带打包器，`mimetype` 规范存放，Apple Books / Calibre / 微信读书等可直接打开 |
| 速度档位 | 标准 / 快速 / 极速三档，命中 `429`、`503` 自动降档 |

## 使用方法

### 1. 安装脚本

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展；
2. 在地址栏打开下面的安装地址，Tampermonkey 会自动弹出安装页，点击「安装」：

   ```text
   https://raw.githubusercontent.com/chenhcy2hj/bilinovel-epub/main/bilinovel-epub.user.js
   ```

3. 确认脚本在 `www.linovelib.com`、`w.linovelib.com` 上处于启用状态。

> 也可以下载 [`bilinovel-epub.user.js`](./bilinovel-epub.user.js)，把内容整体粘贴进 Tampermonkey 的「添加新脚本」后保存。

### 2. 导出分卷

1. 打开任意**分卷详情页**，例如 `https://www.linovelib.com/novel/2771/vol_132334.html`；
2. 点击「目录」标题旁的 **EPUB下载**；
3. 按钮文字即进度：`读取本卷目录…` → `抓取中: 章节 x/y (第n页)` → `下载图片: a/b` → `正在打包 EPUB…` → `打包完成 x.xMB/y.ys`；
4. 结束后浏览器自动下载 `书名 - 卷名.epub`。

抓取期间可以随时打开控制台（F12）查看详细日志。一次只处理当前分卷，同一时间只允许一个任务在跑。

### 3. 可选设置

点击 Tampermonkey 图标 → 本脚本的菜单命令：

| 菜单项 | 作用 |
| :--- | :--- |
| 速度档位 | 标准 `safe`（800–1500ms / 3 并发）、快速 `fast`（500–900ms / 6 并发，默认）、极速 `turbo`（250–500ms / 8 并发） |
| 导入 PUA 字符字典 (JSON) | 追加自定义映射，格式 `{"\ue800":"的", ...}` |
| 导入轮廓 Hash 字典 (JSON) | 追加字形轮廓映射，格式 `{"a1b2c3d4":"的", ...}` |
| 清理字体缓存 | 清除已缓存的字体与动态映射 |

正文请求始终串行，档位只影响请求间隔与插图并发；这是站点反爬约束，不建议改成并发抓正文。
